Cette extension n'est ni éditée, ni approuvée, ni sponsorisée par AUTO1 Group ni par Leboncoin. Ces noms appartiennent à leurs propriétaires et ne sont cités que pour décrire les services avec lesquels l'extension fonctionne.

2. Ce que fait l'extension

Une seule fonction : aider un négociant automobile professionnel à repérer les annonces rentables parmi celles que la plateforme Auto1 lui affiche. Selon la configuration du serveur d'analyse, l'extension lit, dans l'onglet Auto1 du négociant, la liste des véhicules et, à la demande du serveur, la fiche de quelques annonces ; ou bien elle se limite à lire, à la demande du serveur, la page d'une annonce à la fois pour en obtenir le prix. Elle transmet ces informations au serveur d'analyse configuré par l'utilisateur, qui calcule un score, une marge potentielle et une enchère conseillée, puis renvoie le résultat à l'extension pour affichage.

Ce que l'extension ne collecte pas : aucun mot de passe, aucun cookie, aucune donnée de formulaire, aucune donnée sur d'autres sites que www.auto1.com, aucun historique de navigation, aucune identité de l'utilisateur. 4. Destinataires et transferts

  • Serveur d'analyse : exploité par l'éditeur ou par le prestataire de l'utilisateur. C'est le seul destinataire des données de l'extension.
  • Service de tunnel : lorsque le serveur est joint par internet, les échanges, chiffrés en HTTPS, transitent par un service de tunnel (actuellement ngrok) qui peut techniquement les traiter pour les acheminer. Il n'a pas d'autre usage de ces données.
  • Leboncoin : pour estimer la valeur de revente, le serveur recherche sur Leboncoin des annonces comparables (marque, modèle, année, kilométrage, carburant). Aucune donnée personnelle de l'utilisateur n'est envoyée.

Les données ne sont ni vendues, ni louées, ni utilisées pour de la publicité, ni transférées à des courtiers en données, ni utilisées pour évaluer une solvabilité ou accorder un crédit. Elles ne sont lues par un humain que pour assurer le support à la demande de l'utilisateur, pour la sécurité du service ou pour respecter la loi.

5. Sécurité

Les échanges avec un serveur distant passent obligatoirement par HTTPS ; l'extension refuse une adresse distante en clair. L'accès au serveur exige un jeton. Un site web ne peut pas alimenter le serveur : celui-ci n'accepte que les messages de l'extension. Le serveur ne demande à l'extension de lire que des fiches d'annonces de l'origine Auto1 ; l'extension refuse toute autre adresse.

6. Conservation

Dans l'extension : jusqu'à ce que l'utilisateur vide la liste ou désinstalle l'extension. Sur le serveur : les analyses sont conservées tant qu'elles servent la finalité décrite ci-dessus et supprimées à la demande de l'utilisateur.

7. Vos droits

Vous pouvez demander l'accès à vos données, leur rectification ou leur effacement en écrivant à l'adresse de contact ci-dessus. Vous pouvez aussi saisir l'autorité de protection des données de votre pays (en France, la CNIL).

8. Utilisation limitée

L'utilisation par cette extension des informations reçues de la plateforme Auto1 respecte la politique relative aux données utilisateur du Chrome Web Store, y compris les exigences d'utilisation limitée. Ces informations servent uniquement à fournir la fonction décrite à la section 2.

9. Modifications

Toute modification importante de cette politique sera publiée sur cette page, avec une nouvelle date de mise à jour, avant d'entrer en vigueur.

Privacy policy

Chrome extension “Analyse d'annonces pour négociants auto” (car-dealer listing analysis) · version 1.0 · last updated: 28 October 2026

1. Who is responsible

Publisher and data controller: Sacha Martin. Contact for any question or request about your data: martinsacha996@gmail.com.

This extension is not published, endorsed or sponsored by AUTO1 Group or Leboncoin. These names belong to their owners and are used only to describe the services the extension works with.

2. What the extension does

One function: helping a professional car dealer spot profitable listings among those the Auto1 platform shows them. Depending on how the analysis server is set up, the extension reads, in the dealer's own Auto1 tab, the list of vehicles and, when the server asks, the detail page of a few listings; or it only reads, when the server asks, one listing's page at a time to get its price. It sends them to the analysis server the user has configured, which computes a score, a potential margin and a suggested maximum bid, and returns the result for display.

It reads only the Auto1 platform's responses to the list request and the detail requests. The server does not keep the raw responses: it keeps only the characteristics needed for the analysis.

4. Recipients and transfers

  • Analysis server: operated by the publisher or by the user's service provider. It is the only recipient of the extension's data.
  • Tunnel service: when the server is reached over the internet, the HTTPS traffic goes through a tunnel service (currently ngrok) that can technically process it to deliver it. It has no other use for this data.
  • Leboncoin: to estimate resale value, the server searches Leboncoin for comparable listings (make, model, year, mileage, fuel). No personal data about the user is sent.

Data is not sold, rented, used for advertising, transferred to data brokers, or used to determine creditworthiness or for lending. A human reads it only to provide support at the user's request, for security, or to comply with the law.

5. Security

Exchanges with a remote server must use HTTPS; the extension rejects a remote address in clear text. Access to the server requires a token. A web page cannot feed the server: it accepts only the extension's messages. The server can only ask the extension to read Auto1 listing detail pages; the extension refuses any other address.

6. Retention

In the extension: until the user clears the list or uninstalls the extension. On the server: analyses are kept as long as they serve the purpose described above and are deleted at the user's request.
